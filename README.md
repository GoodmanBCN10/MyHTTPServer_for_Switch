The idea came about after seeing many people downloading games to their phones but not knowing how to transfer them to the Switch.

With MyHTTPServer, you can install them using DBI, just like you would with the MTP Responder option. All you need are the nsp or nsz files in a folder that you select when you launch the app. When you start the server, it will provide the phone's IP address to tell DBI where to search for the files.
