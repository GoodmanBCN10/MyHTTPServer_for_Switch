**My HTTP Server for Switch**

**Transfer files from your Android device to your Nintendo Switch using HTTP protocol and DBI**

My HTTP Server for Switch is an Android application designed for Nintendo Switch users who keep their files on their mobile device.
The app creates a simple HTTP server on your local network, allowing DBI on the Nintendo Switch to access the files directly from your Android device.

✨ **How it works**
Select the folder containing your files on your Android device.
Start the HTTP server.
The app displays the IP address and port of the server.
Open **DBI** on your Nintendo Switch.
Use **Explore HTTP, FTP, GitHub**.
Enter the address provided by the app.
Browse the files directly from DBI.

No PC is required.

📱 **Features**
Simple and lightweight Android application.
HTTP server running directly on your phone.
Select any folder to share.
Displays the local IP address and port.
Designed to work with DBI's HTTP browser.
Useful for transferring files without using a computer.
Works over your local Wi-Fi network.

🎯 **Why?**
Many Nintendo Switch users download files directly to their Android device, for example through torrent clients or Telegram.
My HTTP Server for Switch provides a simple way to make those files available to the Nintendo Switch without first having to transfer them to a PC.

**Phone → Wi-Fi → Switch → DBI**

⚠️ **Requirements**
Android device
Nintendo Switch running a compatible CFW setup
DBI installed on the Nintendo Switch
Android device and Nintendo Switch connected to the same local network.
